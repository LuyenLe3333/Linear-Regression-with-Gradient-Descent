## Linear Regression with Gradient Descent (Java)
A command-line machine learning application built in Java that implements linear regression using batch gradient descent.

## Key Features
- Implemented batch gradient descent from scratch in Java
- Applied z-score normalization to improve training stability and convergence
- Performed train/test split for model evaluation
- Defined convergence criteria based on loss reduction (SSE/MSE)
- Outputs model predictions and performance metrics via command line
